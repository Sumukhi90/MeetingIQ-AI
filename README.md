## 🖥️ Project Overview

MeetingIQ is a modern meeting workspace inspired by contemporary AI meeting assistant platforms.

The application provides a centralized interface for managing meetings and accessing meeting intelligence. It includes a dashboard for upcoming and recent meetings, searchable meeting history, calendar views, highlights, action items, and an AI-powered meeting intelligence interface.

The application is designed with reusable React components and a responsive layout to provide a consistent experience across different screen sizes.
